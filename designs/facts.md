# 不编造，标清示意 — Style Reference

> 数字、金额、原话、比例都要能在材料里找到；没有就标示意或待补，页面上注明。

**想说明：** 内容可信  
**分类：** 规范  

这条是文字经验，没有样例，所以没有样式 token；下面只保留做法和提示词。

## 适用场景

- 所有内容

## Do's and Don'ts

### Do

- 示意 / 教学推演 / 真实材料 / 待补分开标
- 内容和文字稿冲突时以文字稿为准，先指出冲突

### Don't

- 为了好看加百分比、金额

## Agent Prompt Guide

```text
做一页「不编造，标清示意」形式的 HTML 演示：内容可信。
适用：所有内容。

避免：为了好看加百分比、金额。
```
