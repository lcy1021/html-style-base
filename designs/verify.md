# 逐页逐步截图验证 — Style Reference

> 用 Playwright 逐页逐步截图，拼成总览图检查；同时看控制台报错、动画中途状态、翻页链路。

**想说明：** 每轮改完都能发现重叠、截断、空白  
**分类：** 工具与交付  

这条是文字经验，没有样例，所以没有样式 token；下面只保留做法和提示词。

## 适用场景

- 每轮修改后

## Do's and Don'ts

### Do

- 1280×680 必查，1920、2560 抽查
- 改动前留 history 备份，静态资源升 ?v=

### Don't

- 通用类名冲突（.why .ok .rv）

## Agent Prompt Guide

```text
做一页「逐页逐步截图验证」形式的 HTML 演示：每轮改完都能发现重叠、截断、空白。
适用：每轮修改后。
做法：1280×680 必查，1920、2560 抽查；改动前留 history 备份，静态资源升 ?v=。
避免：通用类名冲突（.why .ok .rv）。
```
