# 一个案例讲到底 — Style Reference

> 一节只用一个案例从头讲到尾，比多个案例各讲一点更连贯；同一案例不在两处完整重讲，只回扣一句。

**想说明：** 少而深  
**分类：** 讲法  

这条是文字经验，没有样例，所以没有样式 token；下面只保留做法和提示词。

## 适用场景

- 案例较多的分享

## Do's and Don'ts

### Do

- 标准、方法都挂在这个案例上讲

### Don't

- 开场和正文重复拆同一个案例

## Agent Prompt Guide

```text
做一页「一个案例讲到底」形式的 HTML 演示：少而深。
适用：案例较多的分享。
做法：标准、方法都挂在这个案例上讲。
避免：开场和正文重复拆同一个案例。
```
