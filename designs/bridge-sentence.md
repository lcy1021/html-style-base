# 每段第一句承接上一段 — Style Reference

> 例：“从零开始，是什么都没有。更常见的反而是另一种情况：方案已经有了。”

**想说明：** 页与页之间连贯  
**分类：** 讲法  

这条是文字经验，没有样例，所以没有样式 token；下面只保留做法和提示词。

## 适用场景

- 演讲稿、文字稿

## Do's and Don'ts

### Do

- 同一节多个案例之间也写过渡
- 先抛问题，再给答案

### Don't

- 念清单式的稿子

## Agent Prompt Guide

```text

适用：演讲稿、文字稿。

避免：念清单式的稿子。
```
