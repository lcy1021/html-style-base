# 单文件离线版 — Style Reference

> 各页内联 CSS/JS；外壳页用 Blob + iframe 切页，跳转和全屏经 postMessage 交给外壳（切章节不退出全屏）。

**想说明：** 别人双击就能看  
**分类：** 工程与交付  

这条是文字经验，没有样例，所以没有样式 token；下面只保留做法和提示词。

## 适用场景

- 发群、发邮件、离线演示

## Do's and Don'ts

### Do

- 页面零外部依赖（无 fetch / 模块 / CDN）
- 中文文件名的 zip 用 UTF-8 标记

### Don't

- 飞书 / 企业微信预览不运行脚本：要下载后用浏览器打开

## Agent Prompt Guide

```text
做一页「单文件离线版」形式的 HTML 演示：别人双击就能看。
适用：发群、发邮件、离线演示。
做法：页面零外部依赖（无 fetch / 模块 / CDN）；中文文件名的 zip 用 UTF-8 标记。
避免：飞书 / 企业微信预览不运行脚本：要下载后用浏览器打开。
```
