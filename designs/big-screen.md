# 大屏适配 — Style Reference

> 宽度用 vw，面板紧跟说明卡；按断点放大字号；内容卡高度随内容。

**想说明：** 投到大屏时不显得空、不显得远  
**分类：** 规范  

这条是文字经验，没有样例，所以没有样式 token；下面只保留做法和提示词。

## 适用场景

- 会议室投屏、2K/4K 显示器

## Do's and Don'ts

### Do

- 1280×680 必查，1920、2560 抽查
- 用断点放大字号；zoom 只用在不含 vw/vh 的块上

### Don't

- 固定 px 宽度 + 贴边定位，大屏中间空一大块
- grid 1fr 把只有一句话的卡片撑满

## Agent Prompt Guide

```text
做一页「大屏适配」形式的 HTML 演示：投到大屏时不显得空、不显得远。
适用：会议室投屏、2K/4K 显示器。
做法：1280×680 必查，1920、2560 抽查；用断点放大字号；zoom 只用在不含 vw/vh 的块上。
避免：固定 px 宽度 + 贴边定位，大屏中间空一大块；grid 1fr 把只有一句话的卡片撑满。
```
