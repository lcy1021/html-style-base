# HTML 设计经验库

做 HTML 演示、分享页、案例讲解页时的设计经验：**先按案例类型找讲法，再按“想说明什么”选展示形式**。每条附可操作的小样例、适用场景、踩过的坑，以及一份从样例实测出来的 `DESIGN.md`（颜色、字级、圆角、阴影、布局、步骤脚本、给 AI 的提示词）。

- 在线：https://lcy1021.github.io/html-style-base/
- 本地：双击 `index.html` 即可，不需要服务。
- 第一批经验来自「UED 需求分析分享」演示项目（2026-11），样例已去业务化。

## 目录结构

```
index.html          主页：分类筛选、搜索、详情面板（左边样例，右边“说明 / DESIGN.md”两个标签）
data/patterns.js    全部经验条目（唯一要手动维护的数据文件）
data/designs.js     自动生成：所有 DESIGN.md 的内容（双击 index.html 也能读）
designs/<id>.md     自动生成：每条一个 DESIGN.md，可下载或交给 AI
tools/gen_design.py 用浏览器打开每个样例，量出实际样式，生成上面两项
demos/              小样例，每个一个 HTML
demos/demo.css      样例共用样式（深色 / 浅色舞台、字体层级）
demos/demo.js       样例共用步进引擎（← → / 空格 / 滚轮 / 按钮）
```

## 新增一条经验

1. 打开 `data/patterns.js`，复制一条，改字段：

| 字段 | 说明 |
|---|---|
| `id` | 英文短名，唯一，也是详情页的链接锚点（`index.html#id`） |
| `title` | 名称 |
| `category` | 分类：案例场景 / 案例展示 / 页面过渡 / 文字布局 / 讲法 / 外部参考 / 工程与交付（可以新增分类，页面会自动出现） |
| `intent` | 想说明什么（卡片上的一行小字，也用于搜索） |
| `summary` | 一两句话说清形式 |
| `when` / `how` / `pitfalls` | 适用场景 / 做法要点 / 踩过的坑，各是一个字符串数组 |
| `demo` | 样例路径，如 `demos/xxx.html`；没有样例就留空字符串 |
| `related` | 相关条目的 `id` 数组（可选），详情里会出现跳转按钮 |
| `url` | 外部参考的原始网址（可选） |
| `tags` `added` `source` | 标签、收录日期、来源项目 |

2. 有样例的话，在 `demos/` 里新建一个 HTML，引入 `demo.css` 和 `demo.js`：
   - `<body data-steps="3" data-caps="第一步说明|第二步说明|第三步说明">`
   - 元素加 `data-s="1"`（第 1 步起出现）或 `data-s="0-1"`（第 0–1 步可见）
   - 需要自定义逻辑时写 `window.onStep = k => { ... }`
   - 浅色舞台给 `body` 加 `class="light"`
3. 重新生成 DESIGN.md（需要 Python + Playwright）：

   ```bash
   pip install playwright && playwright install chromium
   python3 tools/gen_design.py .
   ```

   DESIGN.md 里的颜色、字级等数值都来自样例的实际渲染，不是原始参考网站的取值。
4. 推送到 `main` 分支，一两分钟后线上更新。

也可以直接对 Claude 说“把 XX 加进设计经验库”，它会按上面的格式补条目和样例。

## 分类说明

- **案例场景**：五类案例（任务还原、证据纠偏、路径与状态、方案取舍与适用范围、数据发现），每类给统一讲法和推荐形式。拿到一个案例先看这里。
- **案例展示**：具体的展示形式和样例。
- **外部参考**：值得借鉴的网站，只记录借鉴的规则；样例是我们自己按规则做的，不复制原站素材。
- **页面过渡 / 文字布局 / 讲法 / 工程与交付**：跨形式的通用经验。

## 收录原则

- 每条都要回答“想说明什么”，而不是只描述外观。
- 样例用去业务化的示意内容；需要真实数据的形式（如斜率图）在样例里注明“数据为示意”。
- 踩坑写具体现象和原因，方便别人对照。
- 不放内部客户名称、真实业务数据和原始截图；外部网站只链接，不搬素材。
